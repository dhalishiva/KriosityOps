Every app you run, readable from your pocket

Twelve screens for the Android app, drawn with the same palette, type and signal lamps as ops.kriosity.in. The app names and numbers below are example data. Switch your system to dark mode to see the night theme.

Sign in

Same Supabase account as the web app. Email + password, or a 6-digit email code.

Board and app

The home screen answers "is anything on fire?" in one glance; an app's page answers "where does it live?".

Social log

The lamps turn amber when a channel reaches its cadence and red at twice it. Logging a post resets the lamp.

Numbers and account

Daily user counts come from the 6 AM IST collector. Plan changes happen on the website.

Notes for the build

  • One backend. The app talks to the existing Supabase project with the anon key and the signed-in user's session. Row-level security already limits every query to the user's own rows; the app adds no new tables.
  • Payments stay on the web. Google Play requires its own billing for digital subscriptions bought inside an app, so version 1 shows the plan and the limit but has no buy button and no link to checkout.
  • Identifiers only. If a typed value looks like a key (starts with sk_, rzp_live_, eyJ, or is a long random string in a password-like field), the sheet warns before saving.
  • Offline. The last loaded board is cached and shown with an "Offline · last updated 9:12 AM" bar; edits wait until the network is back.
